العودة إلى الأرض — نسخة السيرفر (تسجيل دخول بقوقل + حفظ النقاط + لوحة المتصدرين)
============================================================================

ماذا يفعل؟
 - يعرض اللعبة على الإنترنت (أو على جهازك) من عنوان ويب واحد.
 - تسجيل الدخول بحساب قوقل، واسم لاعب تختاره أنت (يُحفظ ويمكن تغييره).
 - يحفظ أفضل نتيجة وأعلى مرحلة وصلتَ إليها لكل لاعب.
 - عند انتهاء اللعبة أو خسارة المحاولات تظهر لوحة المتصدرين: 🥇🥈🥉 لأعلى ثلاثة، وتظهر مرتبتك.
 - لا يحتاج أي مكتبات (npm) — فقط Node.js الإصدار 18 أو أحدث.

1) تشغيل تجريبي على جهازك (بدون قوقل)
   node server.js
   ثم افتح  http://localhost:3000  — سيظهر «دخول تجريبي» (اسم فقط) لتجرّب الحفظ واللوحة.
   اضغط 🏆 في أعلى الشاشة (من الشاشة الأولى أو بين المراحل) لفتح اللوحة والحساب.

2) تفعيل تسجيل الدخول بقوقل (مجاني)
   أ) افتح  https://console.cloud.google.com  وأنشئ مشروعاً.
   ب) APIs & Services ▸ OAuth consent screen: اختر External وأكمل الاسم والبريد (أثناء التجربة أضف بريدك في Test users).
   ج) APIs & Services ▸ Credentials ▸ Create credentials ▸ OAuth client ID ▸ نوع التطبيق: Web application.
   د) في Authorized JavaScript origins أضف:  http://localhost:3000   وعنوان موقعك بعد النشر مثل  https://اسم-موقعك.onrender.com
      (لا تضع مسارات؛ العنوان فقط).
   هـ) انسخ «Client ID» وشغّل السيرفر به:
        ويندوز (PowerShell):   $env:GOOGLE_CLIENT_ID="ضع-المعرّف-هنا"; node server.js
        لينكس / ماك:          GOOGLE_CLIENT_ID=ضع-المعرّف-هنا node server.js
   عندها يظهر زر «Sign in with Google» في اللوحة، ويتوقف الدخول التجريبي تلقائياً.
   ملاحظة: يعمل زر قوقل فقط حين تفتح اللعبة من عنوان السيرفر (http/https) وليس من ملف على الجهاز.

3) النشر على الإنترنت (خيارات مجانية/رخيصة)
   - Render.com أو Railway.app أو Fly.io: ارفع هذا المجلد (أو من GitHub)، أمر التشغيل  node server.js ،
     وأضف متغير البيئة  GOOGLE_CLIENT_ID  (واختيارياً SESSION_SECRET).
   - مهم: النتائج تُحفظ في ملف داخل مجلد data. بعض الاستضافات المجانية تمسح الملفات عند إعادة التشغيل،
     فاربط «Persistent Disk/Volume» واجعل المتغير DATA_DIR يشير إليه (مثل /data). يوجد Dockerfile جاهز.
   - بعد النشر أضف عنوان موقعك إلى Authorized JavaScript origins في قوقل (الخطوة 2-د).

4) مع تطبيق ويندوز
   ضع عنوان السيرفر (سطر واحد، مثل https://اسم-موقعك.onrender.com) في ملف نصي اسمه server.txt بجانب ReturnToEarth.bat
   فتفتح اللعبة من السيرفر وتعمل لوحة المتصدرين وتسجيل قوقل داخل نافذة التطبيق.

الأمان والغش
 - السيرفر يتحقق من هوية قوقل بنفسه، ويمنع تكرار الأسماء، ويحدّ من معدل إرسال النتائج،
   ويرفض النتائج الأكبر من حد معقول لكل مرحلة. لكن اللعبة تعمل داخل متصفح اللاعب، فمن يملك مهارة تقنية
   قد يرسل نتيجة معقولة الشكل مزيّفة. المنع التام يتطلب تشغيل منطق اللعبة على السيرفر نفسه.
